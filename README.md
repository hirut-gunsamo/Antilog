
# Antilog — SIM & Inventory Management System

A full-stack, multi-branch business management system designed to streamline SIM card sales, airtime distribution, inventory management, and financial reporting.

### 🌐 Live Application
**[Visit Antilog](https://antylog.com/)**

## 📌 Project Overview

Antilog is a business management platform built to simplify daily operations across multiple branches.

The system enables business owners, supervisors, and sales employees to manage stock, monitor sales, process inventory requests, and generate reports through a centralized dashboard.

## 🚀 Key Features

### 📊 Dashboard & Reporting
- Daily, weekly, monthly, and yearly sales reports
- Branch-level sales and inventory summaries
- Stock availability and transaction tracking
- Centralized business performance monitoring

### 📦 Inventory Management
- SIM card inventory tracking
- Airtime voucher management
- Stock allocation across multiple branches
- Automatic inventory deductions after sales
- Remaining stock monitoring

### 👥 Role-Based Access Control
- **Owner:** Full access to branches, users, inventory, and reports
- **Supervisor:** Manages branch stock, requests, and sales reports
- **Sales:** Records transactions and submits stock requests

### 🏢 Multi-Branch Management
- Manage multiple business branches
- Assign supervisors and sales employees
- Monitor individual branch performance
- Add and manage new branches

### 🔐 Security
- User authentication
- Role-based authorization
- Protected application routes
- Controlled access to business data

## ⚙️ Installation

### Prerequisites
- Node.js
- pnpm
- PostgreSQL

### Clone the Repository

```bash
git clone https://github.com/hirut-gunsamo/Antilog.git
cd Antilog
```

### Install Dependencies

```bash
pnpm install
```

Configure the required database connection and application environment variables.

Refer to the project's package files for the appropriate development and database setup commands.
